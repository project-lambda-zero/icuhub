# Security Policy

ICUHUB brokers credentials and executes actions against enterprise systems. Treat every
defect in authentication, tenant isolation, policy evaluation, approval handling,
credential handling, webhook verification, or audit integrity as a security issue.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories
("Report a vulnerability" on the repository Security tab). Do not open public issues for
security reports.

Include: affected component, version or commit, reproduction steps, and impact.

## Scope

In scope: everything in this repository. Out of scope: vulnerabilities in vendor products
that ICUHUB connects to (report those to the vendor).
